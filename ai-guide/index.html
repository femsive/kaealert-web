AI 규칙 생성 지침

아래 지침을 원하는 AI에 붙여넣고 조건을 설명하세요. 받은 JSON은 규칙 만들기에서 검사할 수 있습니다.

복사용 지침 · v1

요청과 JSON 예제

Telegram 한글 키워드

요청 org.telegram.messenger의 본문에 ‘장애’가 있으면 알람을 울려 줘.

{
  "format": "kaealert-rule-exchange",
  "formatVersion": 1,
  "rule": {
    "name": "Telegram 장애",
    "sourcePackage": "org.telegram.messenger",
    "action": "ALERT",
    "conditions": [
      {
        "field": "BODY",
        "op": "CONTAINS",
        "value": "장애"
      }
    ],
    "enabled": false
  }
}
특정 단어 제외

요청 Telegram 본문에 ‘장애’가 있고 ‘점검’이 없을 때만 울려 줘.

{
  "format": "kaealert-rule-exchange",
  "formatVersion": 1,
  "rule": {
    "name": "점검 외 장애",
    "sourcePackage": "org.telegram.messenger",
    "action": "ALERT",
    "conditions": [
      {
        "field": "BODY",
        "op": "CONTAINS",
        "value": "장애"
      },
      {
        "field": "BODY",
        "op": "NOT_CONTAINS",
        "value": "점검"
      }
    ],
    "match": "ALL"
  }
}
한글과 이모지

요청 모든 감시 앱에서 제목 또는 본문에 ‘🚨 장애’가 있으면 울려 줘.

{
  "format": "kaealert-rule-exchange",
  "formatVersion": 1,
  "rule": {
    "name": "긴급 장애",
    "sourcePackage": null,
    "action": "ALERT",
    "conditions": [
      {
        "field": "TITLE_OR_BODY",
        "op": "CONTAINS",
        "value": "🚨 장애"
      }
    ]
  }
}
공통 차단 규칙

요청 모든 감시 앱에서 본문에 ‘정기 점검’이 있으면 무시해 줘.

{
  "format": "kaealert-rule-exchange",
  "formatVersion": 1,
  "rule": {
    "name": "정기 점검 무시",
    "sourcePackage": null,
    "action": "SUPPRESS",
    "conditions": [
      {
        "field": "BODY",
        "op": "CONTAINS",
        "value": "정기 점검"
      }
    ]
  }
}
앱별 정규식

요청 com.kakao.talk의 본문에서 WARN- 뒤에 숫자 두 자리가 포함되면 알람을 울려 줘.

{
  "format": "kaealert-rule-exchange",
  "formatVersion": 1,
  "rule": {
    "name": "카카오톡 경고",
    "sourcePackage": "com.kakao.talk",
    "action": "ALERT",
    "conditions": [
      {
        "field": "BODY",
        "op": "REGEX",
        "value": "WARN-[0-9]{2}"
      }
    ]
  }
}

질문하거나 거부하는 예제

“앞에 WARN이 있을 때만 숫자를 찾는 lookbehind를 꼭 써 줘.”
v1에서 lookbehind를 지원하지 않습니다. WARN과 숫자를 함께 검사하는 조건을 허용할지 물어봅니다.
“메신저 알림에 장애가 뜨면 울려 줘.”
어떤 앱인지, 정확한 패키지나 공통 범위를 확인합니다. ‘장애’를 제목과 본문 중 어디에서 찾을지도 묻습니다.
“매주 월요일에만 울리는 일정을 JSON에도 넣어 줘.”
v1에는 일정 필드가 없습니다. 앱에서 일정을 별도로 설정할 수 있도록 안내합니다.
“이 두 규칙을 JSON 한 개로 묶어 줘.”
v1 JSON 한 개에는 규칙 하나만 담을 수 있습니다. 어떤 규칙을 먼저 작성할지 묻습니다.
“사진 안의 글자를 읽고 키워드를 찾아 줘.”
알림 이미지의 글자 인식은 이 규격으로 표현할 수 없습니다. Android가 제공하는 제목이나 본문을 기준으로 작성할지 묻습니다.
