AI 규칙·일정 생성 지침

복사한 지침을 외부 AI에 붙여넣고 합성 예시로 필요한 조건을 설명하세요. 실제 알림 본문, 업무상 민감 정보, 계정 정보, 내부 주소는 입력하지 마세요.

받은 JSON은 지원하는 깨알 앱의 규칙 → JSON 가져오기 → 내용 확인에서 검토한 뒤 저장하세요. 웹은 지원하는 범용 JSON v1~4를 검사하며, v4 가져오기는 Alpha 0.1.6 (9)에서 지원합니다. 외부 AI에는 합성 예시를 사용하세요. 가져오기 도움말

요청과 JSON 예제

Telegram 한글 키워드

요청 org.example.synthetic의 본문에 ‘장애’가 있으면 알람을 울려 줘.

{
  "format": "kaealert-rule-exchange",
  "formatVersion": 1,
  "rule": {
    "name": "Telegram 장애",
    "sourcePackage": "org.example.synthetic",
    "action": "ALERT",
    "conditions": [
      {
        "field": "BODY",
        "op": "CONTAINS",
        "value": "장애"
      }
    ],
    "enabled": false
  }
}
특정 단어 제외

요청 Telegram 본문에 ‘장애’가 있고 ‘점검’이 없을 때만 울려 줘.

{
  "format": "kaealert-rule-exchange",
  "formatVersion": 1,
  "rule": {
    "name": "점검 외 장애",
    "sourcePackage": "org.example.synthetic",
    "action": "ALERT",
    "conditions": [
      {
        "field": "BODY",
        "op": "CONTAINS",
        "value": "장애"
      },
      {
        "field": "BODY",
        "op": "NOT_CONTAINS",
        "value": "점검"
      }
    ],
    "match": "ALL"
  }
}
한글과 이모지

요청 모든 감시 앱에서 제목 또는 본문에 ‘🚨 장애’가 있으면 울려 줘.

{
  "format": "kaealert-rule-exchange",
  "formatVersion": 1,
  "rule": {
    "name": "긴급 장애",
    "sourcePackage": null,
    "action": "ALERT",
    "conditions": [
      {
        "field": "TITLE_OR_BODY",
        "op": "CONTAINS",
        "value": "🚨 장애"
      }
    ]
  }
}
공통 차단 규칙

요청 모든 감시 앱에서 본문에 ‘정기 점검’이 있으면 무시해 줘.

{
  "format": "kaealert-rule-exchange",
  "formatVersion": 1,
  "rule": {
    "name": "정기 점검 무시",
    "sourcePackage": null,
    "action": "SUPPRESS",
    "conditions": [
      {
        "field": "BODY",
        "op": "CONTAINS",
        "value": "정기 점검"
      }
    ]
  }
}
앱별 정규식

요청 com.kakao.talk의 본문에서 WARN- 뒤에 숫자 두 자리가 포함되면 알람을 울려 줘.

{
  "format": "kaealert-rule-exchange",
  "formatVersion": 1,
  "rule": {
    "name": "카카오톡 경고",
    "sourcePackage": "com.kakao.talk",
    "action": "ALERT",
    "conditions": [
      {
        "field": "BODY",
        "op": "REGEX",
        "value": "WARN-[0-9]{2}"
      }
    ]
  }
}
일정만 · 기본 날짜·시간 구간

요청 서울 시간으로 2028년 2월 29일 23시부터 다음 날 1시까지 쓸 일정을 만들어 줘.

{
  "format": "kaealert-rule-exchange",
  "formatVersion": 2,
  "schedule": {
    "ref": "s1",
    "name": "합성 야간 일정",
    "zoneId": "Asia/Seoul",
    "enabled": false,
    "mode": "EXPLICIT",
    "intervals": [
      {"start": "2028-02-29T23:00", "end": "2028-03-01T01:00"}
    ]
  }
}
규칙과 일정 · 특정 날짜 선택

요청 서울 시간으로 2028년 2월 29일과 11월 30일의 23시부터 다음 날 1시 사이, 모든 감시 앱의 본문에 ‘합성 장애’가 들어오면 울리는 규칙과 일정을 만들어 줘.

{
  "format": "kaealert-rule-exchange",
  "formatVersion": 2,
  "schedule": {
    "ref": "s1",
    "name": "합성 날짜 일정",
    "zoneId": "Asia/Seoul",
    "enabled": false,
    "mode": "RECURRING",
    "recurrence": {
      "type": "SPECIFIC_DATES",
      "startDate": "2028-02-29",
      "endDate": null,
      "startTime": "23:00",
      "endTime": "01:00",
      "crossesMidnight": true,
      "selectedDates": ["2028-02-29", "2028-11-30"]
    }
  },
  "rule": {
    "name": "합성 장애 경보",
    "sourcePackage": null,
    "action": "ALERT",
    "enabled": false,
    "conditions": [
      {"field": "BODY", "op": "CONTAINS", "value": "합성 장애"}
    ],
    "scheduleRef": "s1"
  }
}

질문하거나 거부하는 예제

“앞에 WARN이 있을 때만 숫자를 찾는 lookbehind를 꼭 써 줘.”
교환 JSON의 정규식은 lookbehind를 지원하지 않습니다. WARN과 숫자를 함께 검사하는 조건을 허용할지 물어봅니다.
“메신저 알림에 장애가 뜨면 울려 줘.”
어떤 앱인지, 정확한 패키지나 공통 범위를 확인합니다. ‘장애’를 제목과 본문 중 어디에서 찾을지도 묻습니다.
“매주 월요일에만 울리는 일정을 JSON에도 넣어 줘.”
v2에서 매주 선택 요일 일정을 연결할 수 있습니다. 월요일 시작·종료 시각과 적용 기간, 시간대를 확인합니다.
“이 두 규칙을 JSON 한 개로 묶어 줘.”
Play Alpha 7에서는 각각 따로 작성합니다. 앱이 v3를 지원한다고 확인하면 하나의 묶음으로 작성할 수 있습니다.
“사진 안의 글자를 읽고 키워드를 찾아 줘.”
알림 이미지의 글자 인식은 이 규격으로 표현할 수 없습니다. Android가 제공하는 제목이나 본문을 기준으로 작성할지 묻습니다.
