고급 규칙 묶음 미리보기

깨알은 지정한 조건으로 알림을 평가합니다. 고급 묶음에서 일반·제외 규칙, 최초 몇 건 무시, 대상별 재알람 대기와 일정을 조합하세요. JSON v4를 비공개 테스트 Alpha 0.1.6 (9)로 가져오면 새 항목은 OFF입니다. 대상 앱을 감시 목록에 등록하고 필요한 규칙·일정과 감시를 켜세요.

붙여넣은 JSON은 브라우저 안에서 검사합니다. 등록 앱, 남은 한도, Pro와 기존 규칙 중복 여부는 앱에서 확인합니다. 일부 앱이 기존 호환 방식으로 처리되는 동안에는 상태형 규칙을 켜지 못할 수 있습니다.

고급 규칙의 평가 순서

공통 제외가 최종 판정이면 횟수와 대기는 그대로입니다. 처음 N개의 고유 사건을 무시하는 단계가 먼저 적용됩니다. 다음으로 같은 대상의 대기를 적용하며, 적격 반복 수신은 대기 기준 시각을 갱신합니다. 두 단계를 통과하면 일반 규칙이 알람 여부를 결정합니다.

깨알 도움말

감시 앱을 등록하고, 필요한 알림에만 깨알 경보를 설정하세요.

처음 설정하기

  1. 깨알에서 알림 접근 설정 열기를 선택하고 Android 설정에서 깨알의 접근을 허용합니다.
  2. 홈의 감시 앱 목록에서 추가할 앱을 선택합니다. 감시 앱의 개별 스위치도 확인하세요.
  3. 새 규칙에 이름, 감시 범위, 조건과 동작을 설정하고 사용 상태를 확인합니다. 준비가 끝나면 전체 감시를 켭니다.

원래 앱의 알림음은 그 앱과 Android가 관리합니다. 깨알 경보는 알림을 받은 뒤 규칙과 일정 등의 판정을 거쳐 따로 울립니다.

규칙 작성하기

앱별 규칙은 해당 감시 앱에만 적용됩니다. 공통 규칙은 모든 감시 앱에 적용될 수 있습니다. 규칙의 이름과 사용 상태를 확인하세요.

한글, 이모지, 기호를 그대로 찾을 때는 포함을 사용하세요. 예를 들어 본문에 🚨 장애가 포함될 때 일치하도록 만들 수 있습니다. 포함하지 않음을 함께 쓰면 제외할 단어를 정할 수 있습니다. 포함과 제외가 모두 충족되어야 한다면 모든 조건을 선택합니다.

패턴이 필요하면 정규식을 사용하세요. 예를 들어 웹 v1에서 WARN-[0-9]{2}는 새 알림 WARN-07의 일부에 일치합니다. 제목 또는 본문은 두 값을 각각 비교합니다. 제목 끝과 본문 시작을 이어서 찾지 않습니다.

여러 규칙이 일치하면 앱의 평가 순서와 계속·중단 설정이 적용됩니다. 계속 평가하는 규칙의 결과는 뒤의 일치가 바꿀 수 있습니다. 연결한 일정이 꺼져 있거나 활성 구간 밖이면 그 규칙은 건너뜁니다.

웹에서 규칙과 일정 만들기

규칙 만들기의 만들 항목에서 필요한 항목을 선택하세요.

  • 규칙만 선택하면 이름·감시 범위·조건·동작을 담은 JSON v1을 만듭니다.
  • 일정만 선택하면 이름·시간대·시간 구간 또는 반복 설정을 담은 JSON v2를 만듭니다.
  • 규칙과 일정을 함께 선택하면 새 규칙에 새 일정을 연결하는 JSON v2를 만듭니다.

일정은 시작과 종료를 직접 지정하는 기본 날짜·시간 구간, 매일, 매주 선택 요일, N일마다, 매월 지정 일자, 특정 날짜 선택 중에서 고를 수 있습니다.

  1. 선택한 항목을 입력하고 JSON 만들기를 누릅니다. 기존 규칙 JSON v1을 폼으로 불러와 조건을 이어서 작성할 수도 있습니다.
  2. 필요하면 합성 제목·본문으로 규칙의 일치 여부를 시험합니다. 결과 형식과 지원 앱 버전을 확인한 뒤 전체 복사를 누릅니다.

웹의 문자열 시험에는 입력한 예시가 사용됩니다. 실제 Android 알림에 어떤 제목·본문이 들어오는지와 기기의 알람 상태는 깨알에서 확인하세요.

깨알에서 JSON 가져오기

  1. 깨알의 규칙 → JSON 가져오기를 열고 복사한 JSON 전체를 붙여넣습니다. 일정만 가져올 때도 같은 메뉴를 사용합니다.
  2. 내용 확인을 누르고 추가할 항목 수, 조건, 일정 시간대와 날짜·시간, 규칙에 연결할 일정, 사용 상태를 확인합니다. 경고가 있으면 내용을 확인한 뒤 저장 여부를 결정합니다.
  3. 새 규칙 저장 또는 새 항목 저장을 누릅니다. 추가된 항목은 규칙·일정 목록에서 확인합니다. 함께 가져온 경우 규칙에 표시된 일정 이름과 일정 목록의 이름을 대조하고 두 항목의 사용 상태를 확인하세요.

규칙 가져오기는 지원되는 범용 JSON v1~4의 새 항목을 추가합니다. 구형 v3의 업무 전용 키·조건은 거부됩니다. Backup은 앱의 별도 복원 기능에서 열며, 지원할 수 없는 구형 업무 전용 Backup은 데이터 교체 전에 거부됩니다.

자주 묻는 질문

감시할 앱을 어떻게 등록하나요?

깨알 홈의 감시 앱 추가 화면에서 설치된 앱을 선택해 등록하세요. 앱 등록과 Android 알림 접근 허용은 각각 확인해야 합니다.

알림 접근 권한은 왜 필요한가요?

다른 앱이 게시한 Android 알림의 제목과 본문을 깨알이 받아 조건을 판정하는 데 필요합니다. 감시 대상 앱을 등록해도 이 권한은 자동으로 허용되지 않습니다.

전체 감시가 꺼져 있으면 어떻게 되나요?

깨알은 새 수신 알림의 감시를 중단합니다. 원래 앱의 알림은 해당 앱과 Android 설정에 따라 계속 표시될 수 있습니다.

규칙이 일치하는데 알람이 울리지 않으면?

먼저 원래 앱 알림이 Android에 도착했는지 확인하세요. 깨알의 알림 접근, 전체 감시와 앱별 스위치, 규칙 활성 상태와 동작, 다른 규칙의 판정 순서, 일정, 알람 출력과 음량을 차례로 확인하세요. 깨알 이력에서 최종 판정과 알람 상태를 볼 수 있습니다.

일정이 있으면 언제 알람이 동작하나요?

규칙에 연결한 일정의 활성 구간 안에서 그 규칙을 평가합니다. 감시와 권한, 규칙 동작 같은 나머지 조건도 충족해야 합니다.

일반 알림 게시 권한과 알림 접근 권한은 무엇이 다른가요?

일반 알림 게시 권한은 깨알이 자체 알림을 표시하는 데 사용합니다. 알림 접근 권한은 깨알이 다른 앱의 Android 알림을 읽는 데 사용합니다.

JSON v1과 v2의 차이는 무엇인가요?

v1은 규칙 하나를 담습니다. v2는 일정 하나를 담고 새 규칙 하나를 그 일정에 연결할 수 있습니다. 이미 저장한 일정에 규칙을 연결하려면 앱에서 규칙을 편집하세요.

어떤 앱 버전에서 가져올 수 있나요?

규칙만 담은 v1은 Google Play 비공개 테스트 Alpha 0.1.2 (5)에서 지원되기 시작했습니다. 일정 또는 규칙과 일정을 담은 v2는 참여 테스터에게 제공되는 Alpha 0.1.3 (6)에서 지원합니다. 기기의 Android 설정에서 앱 → 깨알 → 앱 정보를 열고 설치 버전을 확인하세요.

구버전에서 가져오기 메뉴가 없거나 v2를 읽지 못하면?

비공개 테스트에 참여 중이라면 Google Play에서 호환 버전으로 업데이트할 수 있는지 확인하세요. v1만 지원하는 버전에서는 웹에서 규칙만 선택해 v1을 만들거나 앱에서 일정을 직접 설정할 수 있습니다.

무료 한도와 Pro 조건은 어떻게 적용되나요?

무료 한도는 사용자 규칙 5개와 일정 3개입니다. 사용자 규칙은 공통·앱별과 활성·비활성을 함께 셉니다. 반복 일정과 특정 날짜 선택 일정을 새로 추가하려면 Pro가 필요합니다. 웹에서 JSON을 만들 수 있어도 앱에서 한도와 사용 권한을 다시 확인합니다.

중복이나 겹침 경고가 나오면 어떻게 하나요?

내용이 같은 기존 항목이 있으면 가져오기를 차단합니다. 이름만 같고 내용이 다르면 별도 항목으로 추가할지 확인합니다. 별개 일정의 시간 겹침은 안내로 표시하며 앱에서 함께 보관할 수 있습니다. 반복이 포함된 겹침 확인은 한 달 범위에서 이뤄집니다. 같은 일정 안의 명시 구간이 서로 겹치면 수정해야 합니다.

가져온 규칙과 일정은 바로 켜지나요?

사용 상태를 지정하지 않으면 둘 다 꺼진 상태로 추가됩니다. 켜서 가져오도록 요청한 항목은 미리보기에서 각각 확인해야 합니다. 저장한 뒤 규칙·일정 목록에서 스위치를 확인하세요. 꺼진 일정에 연결된 규칙은 건너뜁니다.

웹에서는 유효한데 앱에서 저장할 수 없으면?

앱의 지원 버전, 앱별 규칙의 대상 설치·감시 앱 등록, Free/Pro 한도, 충돌 여부를 미리보기에서 확인하세요. 저장 뒤 화면을 새로 고치지 못했다는 안내가 나오면 다시 가져오기 전에 규칙·일정 목록에서 추가 여부를 확인하세요.

이미지 알림이나 본문 없는 알림은 어떻게 처리하나요?

깨알이 평가하는 제목과 본문은 앱이 Android 알림에 넣은 값에 따라 달라집니다. 이미지의 글자를 읽는 기능으로 볼 수 없습니다. 본문이 누락된 경우 본문 포함 조건은 일치하지 않습니다. 제목이 제공되면 제목 조건으로 시험해 보세요.

제조사별 배터리 제한이 영향을 줄 수 있나요?

Android 버전과 제조사에 따라 백그라운드 제한의 동작과 설정 위치가 다를 수 있습니다. 알림이 빠진 경우 원래 앱 알림과 깨알 이력부터 비교하고, 필요하면 기기 설정에서 백그라운드 제한 상태를 확인하세요.
